# ST Стоматологія — сайт клініки

Статичний сайт приватної стоматологічної студії (Київ). Без збірки, без залежностей у продакшені: чистий HTML + CSS + vanilla JS.

## Файли

| Файл | Призначення |
|---|---|
| `index.html` | Розмітка, мета-теги, Schema.org (`Dentist` + `FAQPage`), SVG-спрайт іконок |
| `style.css` | Уся стилізація, дизайн-токени, адаптив, `prefers-reduced-motion` |
| `app.js` | Каруселі зі свайпом, before/after, скрол-анімації, форма, мобільне меню |

## Публікація на GitHub Pages

1. Створіть репозиторій і залийте ці файли в корінь (`index.html` має бути на верхньому рівні).
2. `Settings` → `Pages` → `Source: Deploy from a branch` → `Branch: main`, папка `/ (root)`.
3. Через 1–2 хвилини сайт буде доступний за адресою `https://<username>.github.io/<repo>/`.

Альтернативи: Vercel, Netlify, Cloudflare Pages — просто вкажіть корінь проєкту, команда збірки не потрібна.

## Локальний запуск

Достатньо відкрити `index.html` у браузері. Або через локальний сервер:

```bash
npx serve .
```

## Дизайн-система

Токени оголошені в `:root` (`style.css`). Змінюйте кольори в одному місці:

```css
--ink:        #0E0D0B;  /* фон */
--ink-soft:   #16150F;  /* фон секцій */
--bone:       #F2EDE4;  /* основний текст */
--bone-dim:   #A39C8E;  /* приглушений текст */
--brass:      #C8A96A;  /* акцент, золото */
--brass-deep: #8C7238;  /* темний акцент */
```

Типографіка: **Instrument Serif** (заголовки) + **Manrope** (текст), підключені через Google Fonts.

## Мобільний UX

- Свайп-галерея та свайп-слайдер відгуків (`scroll-snap` + drag мишкою на десктопі)
- Липка нижня панель «Дзвінок / Записатися», з'являється після геро-секції
- Off-canvas меню зі свайпом вправо для закриття
- Смуга прогресу читання, автоприховування шапки при скролі вниз
- Акордеони для цін і FAQ, `<details>` як основа — працюють навіть без JS
- Розмір шрифту в полях форми 16px, щоб iOS Safari не зумив сторінку
- Підтримка `env(safe-area-inset-*)` для iPhone з вирізом

## Що потрібно замінити перед запуском

- **Фото.** Зараз використовуються заглушки з `picsum.photos` та `i.pravatar.cc`. Замініть на реальні фото клініки й лікарів (додайте папку `images/` і вкажіть локальні шляхи).
- **Контакти.** Телефон `+380 44 123 45 67`, адреса, email — у `index.html` (шапка, футер, секція контактів, Schema.org).
- **Обробник форми.** У `app.js`, розділ 10, зараз демо-таймер. Підключіть свій endpoint, Formspree, Telegram Bot API або CRM.
- **Домен** у `<link rel="canonical">`, `og:url` та Schema.org.
- **OG-зображення** (`og:image`) — покладіть свою картинку 1200×630.

## Доступність

Семантична розмітка, ARIA для інтерактивних елементів, видимий фокус, skip-link, коректні `alt`, підтримка клавіатури в каруселях, повага до `prefers-reduced-motion`.
